# RANCAGE Brand Assets v1.0

This folder contains the owner-selected RANCAGE icon artwork package.

## Contents

- `vector/RANCAGE-master.svg` — primary four-color vector master traced from the supplied reference PNG.
- `vector/RANCAGE-monochrome-black.svg` — black one-color version.
- `vector/RANCAGE-monochrome-white.svg` — white one-color version for dark surfaces.
- `png/color/` — transparent PNG exports at 16, 32, 64, 128, 256, 512, and 1024 pixels.
- `png/monochrome-black/` — black PNG exports at the same sizes.
- `png/monochrome-white/` — white PNG exports at the same sizes.
- `source/RANCAGE-original-reference.png` — preserved source image supplied for tracing.
- `preview/` — visual previews for checking transparent, light, and dark usage.
- `BRAND-GUIDELINES.md` — basic usage guidance.
- `ASSET-PROVENANCE.md` — how these assets were produced.
- `RIGHTS-STATUS.md` — current registration-status note.
- `SHA256SUMS.txt` — integrity hashes for package files (excluding the hash list itself).

## Recommended use in the repository

Extract this ZIP at the RANCAGE repository root. It creates:

`assets/brand/rancage/`

These are brand assets only. They are not compiler, runtime, or build dependencies.
