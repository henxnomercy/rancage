# RANCAGE Icon — Basic Brand Guidelines

## Primary mark

Use `vector/RANCAGE-master.svg` as the primary vector artwork. It has a transparent background and preserves the selected gold, emerald, deep-green, and mint geometry.

## Palette

| Role | HEX |
|---|---|
| Gold | `#DAA72A` |
| Emerald | `#088A5E` |
| Deep green | `#046844` |
| Mint | `#40B87B` |
| Monochrome black | `#16181D` |
| Monochrome white | `#FFFFFF` |

## Clear space and sizing

- Keep clear space around the icon; a practical starting point is at least 8% of the icon canvas on every side.
- Use the SVG master for scalable layouts.
- PNG exports are provided from 16 px to 1024 px.
- For important product UI, prefer 32 px or larger. The 16 px export is provided for compact contexts and should be visually checked in the actual interface.

## Backgrounds

- Use the color mark on light or dark backgrounds when contrast is sufficient.
- Use the white monochrome variant on dark backgrounds when the color mark lacks sufficient contrast.
- Use the black monochrome variant on light backgrounds when a single-color mark is required.
- The artwork background is transparent; do not add a baked-in background unless a specific product surface requires one.

## Do not

- Stretch, squash, rotate, crop, or skew the symbol.
- Rearrange its colored components.
- Apply arbitrary colors to individual components.
- Add text inside the symbol.
- Add shadows, bevels, or gradients that change the core mark.
- Trace the PNG again when the vector master is available.

## Status

This package records the currently selected RANCAGE icon artwork. It does not mean that the trademark has been registered or that a copyright record has been issued.
