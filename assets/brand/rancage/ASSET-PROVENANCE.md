# RANCAGE Brand Asset Provenance

## Source

The source artwork is the 512 x 512 RGBA PNG supplied by the project owner in this conversation and preserved at `source/RANCAGE-original-reference.png`.

## Vectorization

`vector/RANCAGE-master.svg` was generated by tracing the source PNG's flat-color regions into SVG paths. The source has a transparent background and four dominant colors. The SVG contains editable vector paths rather than an embedded raster image.

The trace follows the source pixels. It is a traced vector reconstruction, not the original authoring file or a claim of mathematically exact recovery of the original design geometry.

## Exports

PNG variants were rendered from the SVG master. Monochrome variants reuse the same traced geometry with a single paint color.

## Trace utility

The Python tracing utility is intentionally not included in this brand asset package. It is an internal production utility and is not required to use the SVG or PNG assets. Keep its separate archival copy if future regeneration is needed.
